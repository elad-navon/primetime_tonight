# מה יש בפריים טיים?

דף אינטרנט להצגת לוח השידורים של ערוצי הטלוויזיה המרכזיים וספורט 5, עם
דגש על תוכניות הפריים טיים.

הדף מושך את נתוני השידורים בזמן אמת מ-API של yes ומציג אותם בממשק כהה,
מודרני ורספונסיבי.

## מה הדף מציג?

-   פריים טיים בין 21:00 ל-24:00 (בערוצי הספורט: החל מ-18:00)
-   לוח שידורים מלא עד חצות
-   בחירת יום להצגת לוח עתידי
-   שעון ישראל בזמן אמת
-   סטטוס לכל תוכנית:
    -   משודר עכשיו
    -   הסתיים
    -   תוכנית הבאה
-   פס התקדמות בזמן שידור
-   תמונות ותיאורים של תוכניות כאשר הנתונים זמינים
-   אפשרות לפתוח תוכניות נוספות בתוך כל ערוץ
-   אפשרות לבחור תוכנית לספוטלייט בראש הכרטיס
-   סינון לפי:
    -   כל הערוצים
    -   ערוצים 11, 12, 13
    -   ערוצי ספורט 5
-   הסתרה אוטומטית של מהדורות חדשות בפריים טיים
-   אפשרות להציג מחדש את החדשות
-   רענון ידני
-   רענון אוטומטי של התצוגה בכל דקה
-   משיכת נתונים מחדש מה-API בכל 5 דקות
-   Favicon ואייקון אפליקציה מותאמים אישית (מלבן ירוק עם "PT")
-   אפשרות התקנה כאפליקציה (PWA) על מסך הבית בנייד

## מקור הנתונים

הנתונים נמשכים בזמן אמת מה-API של yes:

`https://svc.yes.co.il/api/content/broadcast-schedule/channels/`

לכל ערוץ מתבצעת בקשה נפרדת לפי התאריך הנבחר.

הדף משתמש ב-API ישירות מהדפדפן, ולכן נדרש חיבור לאינטרנט בזמן השימוש.

## אזור זמן

כל הזמנים בדף מוצגים לפי:

`Asia/Jerusalem`

הקוד מטפל באופן מפורש בהמרת תאריכים ושעות בין שעון ישראל ל-UTC, כדי
שהשעות יוצגו נכון גם אם המחשב נמצא באזור זמן אחר.

## מבנה הפרויקט

עיקר האפליקציה בנוי כקובץ HTML יחיד:

``` text
index.html
```

הקובץ כולל בתוכו HTML, CSS, JavaScript ו-Favicon מוטמע (בגודל קטן).

לצידו נמצאים קבצים נוספים הדרושים להתקנה כאפליקציה (PWA):

``` text
manifest.json      – הגדרות ה-PWA (שם, צבעים, אייקונים)
sw.js              – Service Worker בסיסי, נדרש כדי שהדפדפן יאפשר התקנה
icons/             – אייקוני האפליקציה בגדלים שונים, כולל גרסת maskable
TVAVATAR.jpg       – תמונת ההשראה לעיצוב הלוגו (לא בשימוש ישיר בבנייה)
```

אין צורך בשרת Backend כדי להפעיל את הממשק, אך התקנה אמיתית כאפליקציה
בנייד (ראו בהמשך) דורשת אחסון בכתובת HTTPS.

## הפעלה

אפשר לפתוח את קובץ ה-HTML ישירות בדפדפן.

מומלץ להשתמש ב-Chrome או בדפדפן מבוסס Chromium.

מכיוון שהדף פונה ל-API חיצוני של yes, סביבת Preview מסוימת עשויה להציג
בקשת הרשאה לגישה לרשת.

במקרה כזה יש לאפשר את החיבור לכתובות של `svc.yes.co.il`.

## Favicon ואייקון האפליקציה

עיצוב אחיד לכל הגדלים: מלבן פינות-מעוגלות בירוק כהה (`#144837`), בלי
רגל, עם הכיתוב "PT" בשחור מודגש (Bold) במרכז. מצויר ישירות בקוד (לא
תמונה מוטמעת). נבחר מתוך סבב של 11 הצעות שהוצגו למשתמש.

-   `icon-16.png` עד `icon-512.png` – המלבן הירוק (עם שוליים שקופים
    סביבו) לשימוש כ-Favicon וכאייקון "רגיל" של ה-PWA.
-   `icon-maskable-512.png` ו-`apple-touch-icon.png` – אלה האייקונים
    שמופיעים בפועל במסך הבית באנדרואיד וב-iOS, ושתי הפלטפורמות לא
    תומכות בשקיפות אמיתית שם (iOS ממלא שקיפות בשחור אוטומטית;
    באנדרואיד האייקון מורכב משכבת "רקע" ושכבת "קדמה" שהמערכת גוזרת
    לצורה שונה בכל לאנצ'ר – עיגול, ריבוע מעוגל וכו' – ותמיד יש שכבת
    רקע אטומה מתחתיו). מכיוון שלעיצוב הזה כבר יש רקע ירוק אחיד משלו,
    הגרסאות האלה פשוט ממלאות את כל הריבוע באותו ירוק (בלי "קופסה"
    בצבע לא קשור), עם הטקסט "PT" מוקטן ומורחק מהקצוות כדי שלא ייחתך
    בגזירה.

גרסת ה-32×32 מוטמעת ישירות בתוך `index.html` באמצעות Base64 עבור
הפאביקון בכרטיסיית הדפדפן; שאר הגדלים נטענים כקבצים נפרדים מתיקיית
`icons/`.

## התקנה כאפליקציה בנייד (PWA)

הדף כולל `manifest.json` ו-`sw.js` (Service Worker) שמאפשרים להתקין
אותו כאפליקציה על מסך הבית בנייד, במקום רק לפתוח אותו כדף אינטרנט.

ה-Service Worker עובד בגישת "רשת קודם" – בכל טעינה הוא מנסה להביא
גרסה עדכנית מהשרת, ורק אם אין בכלל חיבור לרשת הוא נופל חזרה לעותק
השמור מהפעם הקודמת. כך עדכונים לדף (כמו שינוי באייקון) אמורים להופיע
כמעט מיד בפעם הבאה שפותחים את האפליקציה, בלי צורך למחוק ולהתקין
מחדש.

כדי שהתקנה כזו תעבוד בפועל צריך שהדף יוגש מכתובת מאובטחת (HTTPS) –
לדוגמה באמצעות GitHub Pages על הריפו הזה. פתיחה ישירה של הקובץ מהדיסק
(`file://`) לא מספיקה לרוב הדפדפנים כדי להציג אפשרות התקנה.

לאחר שהדף פעיל בכתובת HTTPS:

-   **אנדרואיד (Chrome):** נכנסים לתפריט ⋮ ובוחרים "התקן אפליקציה" /
    "הוסף למסך הבית".
-   **iPhone (Safari):** לוחצים על כפתור השיתוף ובוחרים "הוסף למסך
    הבית".

לאחר ההתקנה האפליקציה נפתחת במסך מלא, עם האייקון והשם שהוגדרו
ב-`manifest.json`, אך עדיין מושכת את הנתונים בזמן אמת מה-API של yes.
