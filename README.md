# מה יש בפריים טיים?

דף אינטרנט להצגת לוח השידורים של ערוצי הטלוויזיה המרכזיים וספורט 5, עם
דגש על תוכניות הפריים טיים.

הדף מושך את נתוני השידורים בזמן אמת מ-API של yes ומציג אותם בממשק כהה,
מודרני ורספונסיבי.

## מה הדף מציג?

-   פריים טיים בין 21:00 ל-24:00
-   לוח שידורים מלא עד חצות
-   בחירת יום להצגת לוח עתידי
-   שעון ישראל בזמן אמת
-   סטטוס לכל תוכנית:
    -   משודר עכשיו
    -   הסתיים
    -   תוכנית הבאה
-   פס התקדמות בזמן שידור
-   תמונות ותיאורים של תוכניות כאשר הנתונים זמינים
-   אפשרות לפתוח תוכניות נוספות בתוך כל ערוץ
-   אפשרות לבחור תוכנית לספוטלייט בראש הכרטיס
-   סינון לפי:
    -   כל הערוצים
    -   ערוצים 11, 12, 13
    -   ערוצי ספורט 5
-   הסתרה אוטומטית של מהדורות חדשות בפריים טיים
-   אפשרות להציג מחדש את החדשות
-   רענון ידני
-   רענון אוטומטי של התצוגה בכל דקה
-   משיכת נתונים מחדש מה-API בכל 5 דקות
-   Favicon מותאם אישית של טלוויזיה לבנה על רקע שחור

## ערוצים

הדף מציג את הערוצים הבאים:

### ערוצים מרכזיים

-   11 - כאן 11
-   12 - קשת 12
-   13 - רשת 13

### ערוצי ספורט

-   55 - ספורט 5
-   56 - ספורט 5+
-   57 - ספורט 5 גולד
-   58 - ספורט 5 לייב
-   59 - ספורט 5 סטארס
-   60 - ספורט 5 מקס

## מקור הנתונים

הנתונים נמשכים בזמן אמת מה-API של yes:

`https://svc.yes.co.il/api/content/broadcast-schedule/channels/`

לכל ערוץ מתבצעת בקשה נפרדת לפי התאריך הנבחר.

הדף משתמש ב-API ישירות מהדפדפן, ולכן נדרש חיבור לאינטרנט בזמן השימוש.

## אזור זמן

כל הזמנים בדף מוצגים לפי:

`Asia/Jerusalem`

הקוד מטפל באופן מפורש בהמרת תאריכים ושעות בין שעון ישראל ל-UTC, כדי
שהשעות יוצגו נכון גם אם המחשב נמצא באזור זמן אחר.

## מבנה הקובץ

הפרויקט כרגע בנוי כקובץ HTML יחיד:

``` text
index_with_new_tv_favicon.html
```

הקובץ כולל בתוכו:

-   HTML
-   CSS
-   JavaScript
-   Favicon מוטמע

אין צורך בשרת Backend כדי להפעיל את הממשק.

## הפעלה

אפשר לפתוח את קובץ ה-HTML ישירות בדפדפן.

מומלץ להשתמש ב-Chrome או בדפדפן מבוסס Chromium.

מכיוון שהדף פונה ל-API חיצוני של yes, סביבת Preview מסוימת עשויה להציג
בקשת הרשאה לגישה לרשת.

במקרה כזה יש לאפשר את החיבור לכתובות של `svc.yes.co.il`.

## Favicon

ה-Favicon מוטמע ישירות בתוך קובץ ה-HTML באמצעות Base64.

העיצוב הוא:

-   רקע שחור
-   טלוויזיה לבנה
-   קווים עבים
-   מסך שחור
-   אנטנות לבנות
-   עיצוב מינימליסטי כדי לשמור על זיהוי ברור גם בגודל קטן

לכן אין צורך לשמור קובץ PNG נפרד עבור האייקון.

## סינון חדשות

הדף מזהה חדשות לפי כותרת התוכנית.

הזיהוי מבוסס על מילות מפתח כגון:

-   חדשות
-   מהדורה
-   מבזק
-   כותרות הבוקר

בגלל שה-API אינו מספק שדה Genre ייעודי, הסינון מתבצע לפי הכותרת.

בערוצי הספורט, "חדשות הספורט" מוחרגות מהסינון ונשארות מוצגות.

## רענון

הדף מבצע שני סוגי רענון:

### רענון תצוגה

פעם בדקה.

משמש לעדכון:

-   השעה
-   סטטוס התוכנית
-   פס ההתקדמות
-   תוכנית שמשודרת כרגע

### רענון נתונים

כל 5 דקות.

בשלב זה מתבצעת שליפה מחדש של נתוני הערוצים מה-API.

## טיפול בשגיאות

אם ערוץ מסוים לא נטען, הדף ממשיך לעבוד ומציג הודעת שגיאה עבור הערוץ
שנכשל.

כך תקלה בערוץ אחד אינה מונעת הצגה של שאר הערוצים.

## טכנולוגיות

הפרויקט משתמש בטכנולוגיות Web סטנדרטיות:

-   HTML5
-   CSS3
-   JavaScript
-   Fetch API
-   Intl.DateTimeFormat
-   CSS Grid
-   Flexbox
-   Responsive Design

אין שימוש בספריות JavaScript חיצוניות.

## רישוי ומקור הנתונים

הפרויקט הוא ממשק צד לקוח המשתמש בנתוני שידורים שמתקבלים מ-yes.

יש להתייחס ל-API ולנתונים בהתאם לתנאי השימוש והזמינות של השירות.

## הערה

הדף תלוי בזמינות ה-API של yes. אם השירות אינו זמין, השתנה מבנה ה-API או
נחסמה הגישה אליו, ייתכן שהנתונים לא ייטענו.
